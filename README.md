## 👨🏻‍💻 Sobre mim

Tenho 23 anos, sou de Tocantins, Minas Gerais, e estudo Engenharia de Software no Unigrande University Center. Gosto de entender **como** e **por que** as coisas funcionam — por isso costumo resolver o mesmo problema em linguagens diferentes só para comparar sintaxe, paradigma e performance. É um jeito de aprender na prática, não só na teoria.

## 🚀 Foco atual

* 🔭 Construindo projetos full stack e explorando diferentes stacks de backend (Go, Python, TypeScript)
* 🧩 Estudando algoritmos e estruturas de dados através de reimplementações comparadas entre linguagens
* 🌐 Aprofundando conhecimento em **APIs**, **bancos de dados relacionais** e **integrações com Supabase**
* 📈 Construindo portfólio real com projetos publicados e documentados no GitHub
* 💬 Aberto a colaborações, code review e trocas com outros devs
